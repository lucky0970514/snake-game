📌 名稱

貪吃蛇小遊戲

🎮 簡介

本專案為使用 Python + Pygame 製作的貪吃蛇小遊戲，
作為課堂程式設計練習，目的是熟悉 Python 基礎語法、事件處理與遊戲邏輯。

遊戲加入不同難度選擇、生命值機制與障礙物，
讓玩法不只限於傳統的貪吃蛇。

🧩 遊戲功能

開始選單，可選擇 簡單 / 普通 / 困難 難度
簡單(Easy)
無障礙物+五條命
普通(Normal)
少量固定障礙物+五條命
困難(Hard)
多量固定障礙物+移動障礙物(有機率扣血)+三條命

不同顏色果實具不同效果
黃色-基礎果實+1分
紅色-加生命值+2分
藍色-短暫加速、免疫+2分

遊戲結束後可重新開始
